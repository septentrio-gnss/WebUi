Project WebUI

WebUI is an internship project developed at Septentrio. The primary goal is to create a generic, multi-platform web interface for the powerful mosaic-g5 p3h GNSS receiver module.

This interface allows configuration, command execution, and real-time monitoring of the receiver's status and position.
